# The Art & Practice of Astral Projection — traduction française

Projet de traduction française critique de **The Art & Practice of Astral Projection**, par Ophiel.

## Objectif

Produire deux sorties distinctes :

1. **Édition française fidèle** : traduction intégrale, lisible, sans ajout interprétatif silencieux.
2. **Édition annotée RSP** : même traduction, accompagnée d'un appareil critique séparant strictement texte source, observation rapportée, procédure, interprétation occultiste et rapprochement phénoménologique.

## Doctrine éditoriale

- aucune invention ;
- aucune fusion de passages ;
- aucune correction doctrinale silencieuse ;
- les ambiguïtés de l'original restent visibles ;
- les termes techniques sont stabilisés dans `TERMINOLOGY.md` ;
- chaque fragment traduit reste traçable vers sa page source ;
- les notes RSP sont physiquement séparées du texte d'Ophiel ;
- une affirmation d'Ophiel n'est jamais présentée comme un fait établi du seul fait qu'elle figure dans l'ouvrage.

## Structure

```text
00_SOURCE/              source primaire
01_ENGLISH/             transcription anglaise de travail
02_TRANSLATION_FR/      traduction française
03_NOTES_RSP/           annotations phénoménologiques RSP
04_CRITICAL_APPARATUS/  sources, claims, comparaisons, questions ouvertes
05_BUILD/               assemblage des éditions
output/                 exports finaux
```
