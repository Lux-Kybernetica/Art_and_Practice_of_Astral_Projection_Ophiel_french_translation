# 04_CRITICAL_APPARATUS

Matériel critique séparé du texte traduit.

Sous-dossiers/fichiers prévus :

- `CLAIMS_OPHIEL.md` : affirmations doctrinales et empiriques attribuées à Ophiel ;
- `SOURCES_CITED_BY_OPHIEL.md` : auteurs et ouvrages mentionnés ;
- `TERMINOLOGY_COMPARISON.md` : rapprochements terminologiques ;
- `OPEN_QUESTIONS.md` : points non résolus ;
- `ERRATA_SOURCE.md` : coquilles ou lectures problématiques du scan.

Le principe est simple : documenter ce que dit le livre avant de décider ce qu'on en pense. Révolutionnaire, apparemment.
