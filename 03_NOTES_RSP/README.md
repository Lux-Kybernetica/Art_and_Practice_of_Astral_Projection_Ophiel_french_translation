# 03_NOTES_RSP

Annotations pour **Rêves et Projections / RSP**.

## Principe

Aucune ontologie d'Ophiel n'est adoptée comme fait par défaut.

Chaque entrée doit distinguer :

- **source** ;
- **phénomène décrit** ;
- **procédure proposée** ;
- **interprétation d'Ophiel** ;
- **rapprochement RSP éventuel** ;
- **niveau de certitude du rapprochement**.

## Gabarit

```markdown
## Entrée RSP-OPH-XXX

Source : Ophiel, PDF p. XX
Type : Observation | Event | State | Transition | Protocol | Interpretation
Texte/source minimal :
Description :
Correspondance RSP :
Incertitude :
Notes :
```

Ne jamais transformer une ressemblance phénoménologique en identité ontologique.
